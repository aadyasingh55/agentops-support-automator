# Resume Bullets

**AgentOps Support Automator** | Python, FastAPI, LangGraph, PostgreSQL, Docker, Next.js

- Architected a multi-agent technical support triage system with ingestion,
  planning, lookup, drafting, human review, and execution nodes.
- Persisted full workflow state history in PostgreSQL, including review
  decisions, trace IDs, node outcomes, and failure fallback states.
- Containerized the API, database, and review console with Docker Compose and
  added pytest coverage for agent routing and workflow behavior.
